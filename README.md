# Boardboard — канбан-доска с real-time синхронизацией

Веб-приложение для управления задачами в стиле Trello/Kanban.
Поддерживает несколько досок, колонки, карточки, метки, роли,
совместную работу и **синхронизацию в реальном времени** через WebSocket.

---

## Быстрый старт

Требуется установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/).

```bash
git clone <https://github.com/PolinaAniskina/Boardboard>
cd Boardboard
docker compose up --build
```

Через 1–2 минуты приложение будет доступно по адресу:

http://localhost:3000

Первый запуск занимает больше времени (устанавливаются зависимости).
Последующие — секунды.

## Возможности

### Пользователи и роли
Регистрация и вход по JWT (Bearer-токен в Authorization).

Две глобальные роли: member и admin.

Владелец доски + роли на уровне доски (участник / админ доски).

Права проверяются и на фронте (UI), и на бэкенде (API).

### Доски

Список доступных досок (собственные + те, где вы участник).

Создание, редактирование, удаление.

Список участников доски с возможностью добавлять/удалять.

### Колонки и карточки

Полный CRUD.

Drag & drop карточек между колонками и внутри колонки
(dnd-kit, оптимистичное обновление с откатом при ошибке).

Drag & drop колонок — изменение порядка.

Позиции сохраняются на сервере.

### Карточки — детали

Название, описание.

Исполнитель (из списка участников доски).

Метки (предопределённые: Баг / Фича / Документация).

Статус (backlog, todo, in_progress, review, done),
автоматически синхронизируется с колонкой при перемещении.

Автор и дата создания/обновления.

### Real-time

WebSocket для каждой доски: ws://.../api/ws/{board_id}?token=<JWT>.

События: card_created, card_updated, card_moved, card_deleted.

Индикатор состояния соединения в шапке доски:

🟢 Live — подключено;

🟡 … — подключение;

🔴 Offline — нет соединения, идут попытки переподключения;

🔴 Auth — невалидный токен / нет доступа к доске.

Автоматический реконнект с экспоненциальной задержкой.

Аутентификация WS: JWT передаётся в query-параметре, сервер
проверяет токен и доступ к доске до установки соединения.

### Безопасность
JWT-токены (HS256, срок жизни 7 дней).

Хеширование паролей (bcrypt).

Проверка прав на каждом эндпоинте.

CORS ограничен localhost:3000.

WS-соединение закрывается с кодом 1008, если токен невалиден
или у пользователя нет доступа к доске.

## Как получить роль admin
По умолчанию все пользователи получают роль member. Чтобы выдать
себе (или другому пользователю) права администратора:

```bash
docker compose exec backend python -m scripts.make_admin <username>
```

После этого нужно выйти и снова войти — роль хранится в JWT-токене,
который выдаётся при логине.


## Разработка (без Docker)
Если нужен быстрый hot-reload и отладка — можно запустить локально.

### Бэкенд
```bash
cd backend
python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows:
.venv\Scripts\activate

pip install -r requirements.txt
uvicorn app.main:app --reload
```
Запустится на http://localhost:8000.

### Фронтенд
```bash
cd frontend
npm install
npm start
```
Запустится на http://localhost:3000.

В этом режиме фронт общается с бэком напрямую
(REACT_APP_API_URL=http://localhost:8000/api). CORS уже настроен.
